# رادار الوعي — نسخة مصححة

برنامج توعية عربي بأربعة مستويات عمرية، يعمل مباشرة بفتح `index.html`، دون تثبيت أو مكتبات خارجية. حُفظ التصميم والمحتوى والشعار وحقوق المؤلف الموجودة في الملف الأصلي.

## النشر على GitHub Pages

1. أنشئ مستودعاً عاماً باسم `awareness-radar` على حسابك.
2. ارفع محتويات هذا المجلد إلى فرع `main`، بما فيها مجلد `.github`.
3. من Settings → Pages اختر GitHub Actions كمصدر النشر.
4. شغّل Publish awareness radar من Actions أو ادفع تعديلاً إلى `main`.
5. افتح الرابط الذي يظهر بعد نجاح النشر في Pages.

يمكن أيضاً رفع `index.html` فقط واختيار Deploy from a branch ثم `main` و`/ (root)` في إعدادات Pages.

## الإصلاحات

- إصلاح زر الصوت قبل اختيار المستوى.
- إصلاح إعادة تصفير تمرين الترتيب مع كل خطوة ومنع النقر المتكرر أثناء الانتقال.
- إيقاف مؤقت السؤال والانتقالات المؤجلة عند مغادرة المرحلة.
- إضافة زر التالي بعد الإجابة لإتاحة قراءة الشرح.
- التحقق من شكل البيانات المخزنة وتحييد إدراج HTML من سجل الأخطاء.
- ربط شهادة الإتمام باستكمال جميع المراحل وضبط طول الاسم وموضع الشعار.
- تسجيل محاولات تمرين الترتيب في إحصاءات الأداء.
- دعم لوحة المفاتيح والتكبير وتقليل الحركة وتحسين قراءة البطاقات.

التقدم يُحفظ في المتصفح على الجهاز، ولا يُرسل إلى خادم. قد يُفقد عند حذف بيانات المتصفح أو حظر التخزين. الانتقال من ملف محلي إلى موقع منشور لا ينقل التقدم تلقائياً.

التعديل تقني؛ لم يُجرَ تدقيق طبي مستقل للمحتوى الأصلي. لا تتضمن هذه الحزمة منح حقوق جديدة للشعار أو النصوص الأصلية.
